# Random Users

Список людей с заголовком Random Users.

## Что умеет приложение

Экран показывает список. Клиент умеет запросить десять человек с `https://randomuser.me/api/`. Этот запрос с экрана не вызывается, поэтому список открывается пустым.

## Стек

SwiftUI, URLSession.

## Запуск

```bash
git clone https://github.com/dpogonia/RandomUsers-UDEMY.git
cd RandomUsers-UDEMY
open JSONDecoder.xcodeproj
```

Запустите схему **JSONDecoder** на симуляторе iPhone. Цель сборки — iOS 18.2.
