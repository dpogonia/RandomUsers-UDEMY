# Random Users

A list titled Random Users.

## What it does

The screen shows a list. The client can request ten people from `https://randomuser.me/api/`. The screen never calls that request, so the list opens empty.

## Stack

SwiftUI, URLSession.

## Run

```bash
git clone https://github.com/dpogonia/RandomUsers-UDEMY.git
cd RandomUsers-UDEMY
open JSONDecoder.xcodeproj
```

Run the **JSONDecoder** scheme on an iPhone simulator. The deployment target is iOS 18.2.
